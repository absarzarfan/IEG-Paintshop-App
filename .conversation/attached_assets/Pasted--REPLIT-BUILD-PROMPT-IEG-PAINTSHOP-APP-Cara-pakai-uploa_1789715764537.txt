## 0. KONTEKS & ATURAN REUSE

Bangun aplikasi produksi **PAINTSHOP APP** untuk PT IEG Manufacturing Indonesia (fabrikasi oil & gas equipment, Batam). Aplikasi terdiri dari dua modul terintegrasi: **Paint Usage Tracker** dan **Paint Stock Management**.

Saya melampirkan `portable-reference/` — package acuan hasil ekstraksi dari RFI Workflow System. Gunakan sebagai **behavioral starting point**, bukan copy-paste produk.

**WAJIB dipakai ulang (COPY DIRECTLY, lalu di-extend):**

| File acuan | Dipakai untuk di Paintshop App |
|---|---|
| `source/shared/types.ts` | Pola shared types + status union + Attachment/Comment/Note. Extend dengan entity paint. |
| `source/backend/workflowPolicy.ts` | Pure & testable transition policy. Pakai polanya untuk lifecycle Paint Job & Stock Opname. |
| `source/backend/timeAndShift.ts` | Shift & business-day. **ADAPT timezone ke `Asia/Jakarta` (WIB, UTC+7)**, bukan `Asia/Bangkok`. Shift 1 07:30–15:30, Shift 2 15:30–23:30, Shift 3 23:30–07:30 — **[KONFIRMASI jam shift paintshop]**. |
| `source/backend/attachmentPolicy.ts` | COPY DIRECTLY: max 10 lampiran/record, max 10 MB, kompresi JPEG/PNG/WebP, PDF tidak dikompres, upload URL diminta dari backend (browser tidak pernah pegang credential storage). |
| `contracts/openapi.yaml` | Pola kontrak API + auth + role. ADAPT semua route dari `/workflow/*` ke `/paintshop/*`. |
| `database/002_normalized_workflow.sql` | Pakai skema **normalized** (BUKAN JSONB snapshot 001) sebagai gaya persistence. |
| `source/backend/partList.ts` | Referensi pola perhitungan kebutuhan material per line → adaptasi jadi perhitungan target cat per Job × Qty. |

**DILARANG dibawa:** branding/nama department RFI, seed user, password/token/bucket ID/URL deployment, `.env`, `node_modules`, `dist`, generated client.

**DILARANG diasumsikan:** `source/frontend/nesting.ts` adalah reference generic rectangle packing — **tidak relevan** untuk paintshop, jangan diimplementasikan. Jangan mengarang aturan konsumsi material, kerf, remnant, atau yield; semua formula cat harus persis seperti Bagian 3 di bawah.

**Stack:** TypeScript end-to-end. React + Vite + Tailwind (mobile/tablet-first untuk form operator), Express/Node backend, PostgreSQL (Replit DB/Neon) + Drizzle ORM, object storage untuk lampiran. Session server-authoritative, idle timeout 30 menit.

## 1. ROLE & HAK AKSES (server-side enforced, jangan andalkan visibility UI)

| Role | Hak |
|---|---|
| **Admin** | CRUD semua master data (Job/Item, SN, Operator, Color, Merek, Material, Packaging, Threshold), kelola user, override & close record, lihat semua audit trail. |
| **Painter / Operator (PIC)** | Input form pengecatan miliknya sendiri, lihat histori & varians miliknya, upload foto hasil. Tidak bisa mengubah record operator lain, tidak bisa mengubah master target. |
| **Paint Store / Warehouse** | Goods Receive, issue lot, input Stock Opname, kelola Lot & Expire Date. Tidak bisa mengubah master target pemakaian. |
| **Supervisor / QC Reviewer** | Approve/Reject record pemakaian yang overconsumption melebihi toleransi, approve hasil opname, komentar. Tidak melakukan mutasi timer/entry operasional. |
| **Procurement (read + alert)** | Lihat dashboard stok, alert near-expiry & low stock, export laporan. Read-only ke transaksi. |

Aturan turunan dari acuan yang tetap berlaku: requestor tidak boleh memutasi record milik user lain; keputusan reject wajib punya alasan non-blank; komentar & catatan bersifat **append-only** (tidak pernah ditimpa diam-diam).

## 2. MODUL 1 — PAINT USAGE TRACKER

### 2.1 Master Data (Fase 1)

**`master_job_item`** — sumber target, persis mengikuti kolom sheet **MASTER FILE**:

```
job_no              string   PK-ish (contoh: B180009, B180030, B190102)
description         string   (COVER AS, GUARD GP GEAR - COVER, SUPPORT AS, ...)
surface_area_m2     numeric  (2, 1.2, 0.6, 3.5, ...)
primer_total_l      numeric  (0.7, 0.45, 0.2, 1.3, ...)
primer_base_l       numeric  (0.56, 0.36, 0.16, 1.04)
primer_hrd_l        numeric  (0.14, 0.09, 0.04, 0.26)
primer_thinner_l    numeric  (0.14, 0.09, 0.04, 0.26)
primer_cost_base    numeric  ($5.20, $3.34, $1.49, $9.66)
primer_cost_hrd     numeric  ($2.29, $1.47, $0.65, $4.25)
primer_cost_thinner numeric  ($0.84, $0.54, $0.24, $1.56)
primer_cost_total   numeric  ($8.33, $5.36, $2.38, $15.48)
topcoat_total_l     numeric  (0.4, 0.3, 0.12, 0.6)
topcoat_base_l      numeric  (0.3, 0.23, 0.09, 0.45)
topcoat_hrd_l       numeric  (0.1, 0.08, 0.03, 0.15)
topcoat_thinner_l   numeric  (0.08, 0.06, 0.02, 0.12)
topcoat_cost_base / hrd / thinner / total   numeric
```
